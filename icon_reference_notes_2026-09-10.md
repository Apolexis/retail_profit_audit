# Примечание по фирменной иконке

Для favicon и PWA пользователь подтвердил возврат прежней композиции: красные и желтые рыбы движутся по кругу вокруг восходящей красной стрелки. Исходный вариант `rybny_analytics_app_icon.png` содержит эту композицию, но имеет темную квадратную подложку; новый темный и светлый варианты должны сохранить сам знак, убрать подложку в прозрачность и различаться только необходимой для контраста тематической обработкой.
