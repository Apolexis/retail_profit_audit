# Эвотор: подтвержденные интеграционные сведения

Проверено 16.09.2026 по официальной документации Эвотора. API Облака доступен по адресу `https://api.evotor.ru/`. Для V2 требуется явно передавать заголовок `Accept: application/vnd.evotor.v2+json`; общая справка также указывает Bearer-авторизацию. Официальный read-only маршрут `GET /stores` возвращает список магазинов.

Предоставленный пользователем токен прошел безопасную проверку через `GET https://api.evotor.ru/stores` с заголовком `Authorization: Bearer <token>` и вернул успешный ответ. Запрос был только на чтение и не создавал, не менял и не синхронизировал данные касс.

Для будущего учета API описывает доступ к магазинам, терминалам, сотрудникам, товарам и документам. Товарные данные могут содержать UUID, код, штрихкоды, алкогольные коды, название, продажную и закупочную цены, количество, единицу измерения, ставку налога, признаки продажи, тип и дополнительные алкогольные поля. Ответы с коллекциями могут быть постраничными и передают `paging.next_cursor`; лимиты доступны через заголовки `X-RateLimit-*`.

Автоматическая передача токена Облака возможна на серверный endpoint `POST /api/v1/user/token`, защищенный токеном приложения стороннего сервиса. Это потребуется только после решения о регулярной интеграции и настройки приложения на портале Эвотора.
