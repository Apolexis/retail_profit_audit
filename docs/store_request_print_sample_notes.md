# Наблюдения по примеру печати заявок

Источник: `/home/ubuntu/upload/primer1.pdf`, страницы 1–5 из 38, просмотрены 18.09.2026.

Каждый печатный лист — плотная монохромная таблица без прикладной шапки: первая строка объединяет складскую группу и операционную дату (например, «Б. М. 18.09.2026»), далее идут названия товаров, компактные колонки магазинов и крайняя колонка «Итог». Строки разбиты на несколько листов согласно выбранной группе магазинов; одинаковый склад Б. М. печатается отдельно для разных наборов магазинов. Визуально это черно-белая сетка с тонкими границами, экономящая бумагу; значения количеств находятся в пересечении товара и магазина, итог — справа.

Для будущего контура заявок следует создать редактируемые **группы печати магазинов** («Область 1», «Город», «Область 2») и позволить добавлять, переименовывать и удалять их. Отдельно создаются **категории печати товара**; категория СРС допускает вложение категории «СРС В/У», а готовая заявка печатается одним листом на каждый магазин для такой объединенной категории. Это наблюдение фиксирует форму макета, а не создает или меняет реальные заявки, товары, цены либо склады.
