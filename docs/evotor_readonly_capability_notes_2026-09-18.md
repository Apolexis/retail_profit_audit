# Проверка возможностей read-only Эвотор Cloud API V2

Проверено 18.09.2026 по официальным источникам: [Обзор API Облака](https://developer.evotor.ru/docs/rest_overview.html) и [получение списка документов](https://developer.evotor.ru/docs/rest_api_get_store_documents.html).

Официальный обзор подтверждает, что Cloud API V2 поддерживает получение данных магазинов, смарт-терминалов и сотрудников, товарной номенклатуры, документов терминала (включая чеки и акты приемки) и данных ОФД. Для постраничных ответов применяется `paging.next_cursor`; перечислены поддерживающие пагинацию коллекции магазинов, терминалов, сотрудников, документов и товаров. API использует `https://api.evotor.ru/`, медиатип `application/vnd.evotor.v2+json` и Bearer/OAuth-авторизацию. Документация одновременно описывает write-методы и массовые операции, поэтому их нельзя задействовать в текущем контуре без отдельного согласования.

Текущая реализация ограничена server-side read-only каталогом и закрепленным соответствием внутренней точки с Эвотор. Пользователь запросил расширить загрузку на другие закрепленные магазины и их доступные документы/продажи/состав чеков. Это технически совместимо с подтвержденными read-only ресурсами, но требует отдельной схемы хранения идемпотентных read-only снимков, ручного сопоставления кассового товара с общим товаром и отдельной приемки данных. Адреса, токены, terminal UUID и произвольный выбор кассы в UI не выводятся.

## Уточнение по маркировке и категориям

Проверка read-only ответа `GET /stores/{store}/products` 18.09.2026 подтвердила поля `id`, `name`, `code`, `article_number`, `barcodes`, `quantity`, `tax`, `parent_id`, `type`, `price` и `cost_price`. В поле `type` текущая закрепленная точка фактически возвращает явные классы маркировки: `DIETARY_SUPPLEMENTS_MARKED`, `CAVIAR_MARKED`, `JUICE_MARKED`, `BEER_MARKED`, `NOT_ALCOHOL_BEER_MARKED` и `WATER_MARKED`, наряду с `NORMAL`. Поэтому синхронизация назначает контролируемую маркировку именно по `type`, а не по названию товара. `parent_id` не содержит имени категории, поэтому категория собирается через отдельный read-only ресурс групп.

Карточки Эвотор, предоставленные пользователем, дополнительно показывают для маркированного пива значения **«Код алкоголя»**, **«Тип алкоголя»** и **«Крепость %»**. В просмотренных V2-строках списка товаров эти детальные атрибуты не пришли, поэтому карточка общей номенклатуры хранит и показывает их только при выборе маркировки «Алкоголь» или «Маркированное пиво». Обратная запись в Эвотор не выполняется.
