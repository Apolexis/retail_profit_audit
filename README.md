# Аналитика «Рыбный»

Внутреннее PWA для управленческой аналитики розничной сети.

## Технологии

- React + TypeScript + Vite;
- Express + tRPC;
- Drizzle + MySQL/TiDB;
- серверный контроль ролей и доступа;
- защищённые серверные интеграции Эвотор и 1С.

## Разработка

```bash
pnpm install
pnpm dev
```

Проверка перед публикацией:

```bash
pnpm test
pnpm check
pnpm build
```
